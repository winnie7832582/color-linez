# 色球 Color Linez

瀏覽器版的「色球」（Color Linez）。9×9 棋盤，把同色的球連成五顆以上即可消除得分，並試著超越右側的王者分數。

## 線上遊玩

- 新設計版：`index.html`
- 復古 Windows 風格版：`classic/index.html`

不需要安裝，直接用瀏覽器開啟即可。

## 操作方式

- 滑鼠：點一顆球拿起來，再點一個空格，球會沿著空格移動過去。
- 鍵盤：方向鍵移動，空白鍵或 Enter 拿起與放下。
- 快捷鍵：F1 規則、F3 顯示下一組、F4 新局、F5 統計。

## 規則

- 開局有 5 顆球，每 1 步如果沒有消除任何線，會冒出 3 顆新球。
- 橫、直、斜任一方向連成 5 顆以上同色球即可消除。
- 一次消除 5 / 6 / 7 / 8 / 9 顆分別得 10 / 12 / 18 / 28 / 42 分。
- 棋盤被填滿時遊戲結束。

## 資料儲存

遊戲進度、排行榜與偏好設定都存在你自己的瀏覽器（localStorage）裡，不會上傳到任何伺服器。
