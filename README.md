# 色球 Color Linez

瀏覽器版的「色球」（Color Linez）。9×9 棋盤，把同色的球連成五顆以上即可消除得分，並試著超越右側的王者分數。

## 線上遊玩

- 新設計版：`index.html`
- 復古 Windows 風格版：`classic/index.html`

不需要安裝，直接用瀏覽器開啟即可。

## 操作方式

- 滑鼠：點一顆球拿起來，再點一個空格，球會沿著空格移動過去。
- 鍵盤：方向鍵移動，空白鍵或 Enter 拿起與放下。
- 快捷鍵：F1 規則、F3 顯示下一組、F4 新局、F5 統計。

## 規則

- 開局有 5 顆球，每 1 步如果沒有消除任何線，會冒出 3 顆新球。
- 橫、直、斜任一方向連成 5 顆以上同色球即可消除。
- 一次消除 5 / 6 / 7 / 8 / 9 顆分別得 10 / 12 / 18 / 28 / 42 分。
- 棋盤被填滿時遊戲結束。

## 朋友挑戰

打完一局後，按右上角的旗子圖示，會產生一組 12 碼的挑戰碼（例如 `0XDW-T580-0Y1F`）。傳給朋友後：

- 朋友貼上挑戰碼（整段邀請訊息也可以），或直接點你分享的連結，就會從跟你一模一樣的開局開始。
- 同一組挑戰碼，每一輪新球的顏色順序都相同，只有走法不同。
- 朋友的畫面上，右側的「王者」會變成你，目標是拿到比你更高的分數。
- 打完後可以把成績回傳給你，一來一往比下去。

挑戰碼裡包含開局種子和你的分數，沒有任何伺服器參與。用連結邀請時，名字會附在連結後面；只貼挑戰碼的話，對方會看到「朋友」。

限制：因為沒有伺服器，分數無法驗證，這是朋友之間的信任制挑戰，不適合拿來做正式比賽。連結邀請需要把遊戲放在網址上（例如 GitHub Pages），挑戰碼則在任何環境都能用。目前只有新設計版（`index.html`）有這個功能。

## 資料儲存

遊戲進度、排行榜與偏好設定都存在你自己的瀏覽器（localStorage）裡，不會上傳到任何伺服器。
